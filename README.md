# FonePaw Screen Recorder

## Overview

FonePaw Screen Recorder is a software tool designed to capture screen activity on Windows systems. It enables users to record video and audio from their displays for various purposes, including tutorials, presentations, and gameplay recording. The application focuses on delivering clear and accurate screen capture with straightforward controls.

## Key Features

**Screen recording with adjustable area selection**  
**Simultaneous audio capture from system and microphone**  
**Real-time annotation during recording**  
**Scheduled recording capability**  
**Export recordings in multiple video formats**  
**Support for webcam overlay during screen capture**  
**Customizable recording settings for resolution and frame rate**
